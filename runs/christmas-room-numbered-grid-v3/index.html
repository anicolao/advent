Drawing rules and changes

The drawing sheet has sectors A–F across and 1–6 down. An entry C2 / 812 / +6 means find 812 in sector C2, then connect through 818. This is a notation example, not an answer.

Each dot has one number. A + command follows consecutive numbers; “join 127” draws one line directly to 127. Continue subsequent + commands from that number. Lift only at the end of the complete entry. Shared junctions stay exact; joins obey the same short-distance limit.

966 dots, one label each. Intermediate points stay exactly on the original lines. The background is now slightly irregular; concealment needs another review. The SVG drawing square is about 348 mm wide: the longest step is about 17.4 mm.
