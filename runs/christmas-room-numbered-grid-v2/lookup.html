  1. Solve the Sudoku. Rows are A–I; columns are 1–9. Every originally blank cell has a lookup row. Printed givens have none.
  2. Find the lookup section for that row letter. Within it, find the cell address; move across to the column headed by its solved digit.
  3. Read the entry: sector / start number / +connections. For example, C2 / 812 / +6 means find dot 812 in drawing sector C2, then connect 813, 814, 815, 816, 817, 818. Stop and lift your pen. This example explains the notation; it is not a puzzle answer.
  4. Tick the lookup row when finished. Work down sections A–I in order. Each instruction starts a separate stroke.

Each dot has two numbers. They name the same location in two different sequences. Follow only the number you need; do not switch to the other number. This allows lines to meet without gaps.

The drawing has sectors A–F across and 1–6 down. These are drawing locations, separate from Sudoku addresses. All consecutive steps are at most 1/20 of the drawing square’s width.
